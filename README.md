# katagami-koubou-lp

オーダーメイド業務アプリ制作「型紙工房」のランディングページです。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | トップページ(サービス紹介・制作事例・料金・お問い合わせ) |
| `demo/mitsumori-seikyu.html` | 見積・請求アプリのデモ版(サンプルデータで操作可能) |
| `terms.html` | 利用規約 |
| `tokushoho.html` | 特定商取引法に基づく表記 |
| `privacy.html` | プライバシーポリシー |
| `images/` | 制作事例(CASE 01)の画面キャプチャ |

ビルドは不要です。HTML・CSS・JavaScriptはすべて各HTMLファイルの中に書かれています。

## ローカルで確認する

`index.html` をブラウザで直接開けば表示できます。

## 外部サービス

- お問い合わせフォーム: Formspree(`index.html` の `#contact-form`)
- 導入申し込み: Stripe の決済リンク
- フォント: Google Fonts

## 更新するときの注意

- `images/` の画面キャプチャには、氏名・施設名を加工したものを使ってください。
- お客様の声(CASE 02)は `index.html` にコメントアウトしてあります。いただいたら差し替えてください。
